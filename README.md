# Pondroot
Pondroot is a trusted bridge between overlooked talent and real employment opportunities. Prepare through voice or typing, recognize confirmed skills, build a truthful résumé, and choose connections through Rooted Network.

MVP includes guest preparation, supported AI writing, voice/type discovery, résumé files, optional accounts and cloud saving, verified partner opportunities and user approved introductions. Transparent Hiring Information includes ATS, application help and written interview practice. Documents and learning are independent tools.
Download PDF requires email with separate optional impact follow up permission; Print/local draft need no email. Account and matching consent are distinct.
Public guidance is self contained. Private planning, research and personal files remain excluded. Use synthetic fixtures. Build only the requested checkpoint and present it for review before commit/push. No deployment or paid service provisioning is implied.
